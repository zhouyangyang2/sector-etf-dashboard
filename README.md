# Sector ETF Quant Dashboard

美国行业 ETF 量化监控看板，包含行业 ETF K 线、持仓、模型解释、因子监控与宏观环境观察。

## 在线访问

部署完成后可通过 GitHub Pages 在任意电脑的现代浏览器中打开。

GitHub Pages 是离线快照，不会冒充实时行情。本机实时版由富途 OpenD 提供行情，页面顶部会明确显示“富途 LV3 实时行情”、市场状态和最后更新时间。

## 本机富途实时版

前提：Futu OpenD 已启动并登录行情。

双击本地项目中的 `us_equity_qlib/start-sector-etf-live.command`。启动器会：

1. 通过富途补齐最近的已完成日 K；
2. 启动只读行情服务；
3. 每 2 秒刷新 11 只行业 ETF 的最新价、涨跌、买卖价和成交量；
4. 在 K 线中显示 `LIVE` 价格线。

服务只绑定 `127.0.0.1`，不开放账户、持仓或交易接口。日频模型只使用已完成 K 线，盘中报价不会进入模型。

## 数据说明

- 页面是独立静态 HTML，展示的是构建时已封装的数据快照。
- 页面不会连接交易账户，也不会自动下单。
- 模型输出仅用于研究与模拟盘监控，不构成投资建议。
